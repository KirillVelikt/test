# Юмани Терминал

Терминал (APK на телефоне) + пульт (EXE на ПК) + установщик.

## Как собрать
1. `py new.py` — залить всё на GitHub (токен спросят).
2. Вкладка **Actions**: две зелёные галочки.
3. Качать из Artifacts:
   - `app-debug-apk` — приложение-терминал на телефон;
   - `TerminalControl-EXE` — пульт для ПК (без установки);
   - `TerminalControl-Installer` — установщик пульта.

## Как пользоваться
1. Установи APK на телефон (в одной Wi-Fi сети с ПК).
2. На терминале появится код из 8 цифр.
3. Запусти пульт на ПК (EXE или через установщик).
4. Введи код → «ПОДКЛЮЧИТЬ». Статус: «подключено ✓».
5. Введи сумму → «ЗАПУСТИТЬ ОПЛАТУ». На телефоне откроется экран оплаты:
   - **оплатить улыбкой** — камера, снимок, оплата проходит;
   - **по QR** — сканируй код любым приложением банка.
6. Результат («оплата прошла ✓» / «не прошла») вернётся на пульт со звуком.

## Экран оплаты не сворачивается
Приложение просит право «поверх других окон», держит экран включённым
и блокирует «назад», пока идёт оплата.

## Протокол (для своих доработок)
UDP, Wi-Fi сеть:
- пульт → широковещательно `PAIR:<код>` на порт 45555; терминал отвечает `ACK:<код>`;
- пульт → `PAY:<сумма>` терминалу;
- терминал → широковещательно `RESULT:OK:<код>` или `RESULT:FAIL:<код>` на порт 45557.

## Важно
«Оплата улыбкой» — демо-механика: фото снимается и оплата подтверждается,
но реальное распознавание улыбки требует платёжного сервера.
QR тоже демо: сканирование открывает ссылку `yumani://pay?...`,
реальное списание возможно только при интеграции с платёжной системой.
