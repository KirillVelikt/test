# Yumani Terminal

Экран оплаты в стиле Yumani Pay: QR, улыбка, NFC — плюс пульт для ПК.

## Протокол (UDP, локальная Wi-Fi сеть)
- Терминал рассылает маячок каждые 2 сек: порт 45555, `YUMANI_BEACON|код|имя`
- Пульт слушает 45555, при первом подключении терминала открывает окно ввода суммы
- Пульт отправляет оплату на порт 45557 терминала: `PAY|сумма` (с привязанного порта 45558)
- Терминал отвечает на тот же сокет: `RESULT|ok|сумма` или `RESULT|fail|сумма`

## Сборка
- APK: GitHub Actions → workflow Build APK → артефакт app-debug-apk
- EXE + установщик: workflow Build EXE → артефакты TerminalControl-EXE, TerminalControl-Installer

## Оговорка
Оплата «улыбкой» и по NFC — демо-поток: камера/NFC срабатывают, оплата подтверждается,
но реальное списание денег требует платёжного сервера и сертификации.
