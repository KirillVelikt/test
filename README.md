# Yumani Терминал

Полный комплект: приложение-терминал (APK) + пульт для ПК (EXE) + установщик.

## Сборка на GitHub Actions
1. Загрузите всё содержимое этой папки в репозиторий (py new.py).
2. Дождитесь двух зелёных галочек в Actions.
3. Из Artifacts скачайте: app-debug-apk, TerminalControl-EXE, TerminalControl-Installer.

## Как пользоваться
1. Установите APK на планшет терминала. На экране появится 6-значный код.
2. Установите пульт через установщик на ПК (та же Wi-Fi сеть).
3. В пульте введите код с экрана терминала — пульт найдёт его в сети.
4. Введите сумму, нажмите Оплатить — на терминале откроется экран оплаты.
5. Покупатель платит: по QR или улыбкой (камера). Результат приходит на пульт со звуком.

## Протокол (UDP)
- Терминал каждые 2 сек шлёт YUMANI|КОД на 255.255.255.255:45555
- Пульт шлёт PAY СУММА на ip_терминала:45557
- Терминал отвечает RESULT OK / RESULT FAIL на пульт:45557

## Примечание
Оплата улыбкой — демо-поток: камера снимает, оплата подтверждается через 1,5 сек.
Для настоящего распознавания улыбки нужен платёжный сервер.
