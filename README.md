# Юмани Терминал — полная сборка

## Состав
- **APK** (телефон-терминал): экран кода, оплата улыбкой (камера), оплата по QR, поверх окон, звуки
- **Пульт для ПК** (`pc-control/terminal_control.py`): подключение по коду, отправка суммы, звуковой сигнал результата. Запуск: `python terminal_control.py` (GUI) или `python terminal_control.py --cli`
- **Установщик** (`installer/terminal_installer.iss`): Inno Setup, ставит пульт в Program Files с ярлыками

## Сборка на GitHub (два workflow)
1. **Build APK** → артефакт `app-debug-apk`
2. **Build EXE** → артефакты `TerminalControl-EXE` и `TerminalControl-Installer`

## Как это работает
- Телефон и ПК в одной Wi-Fi сети
- Пульт рассылает `YMNI_DISCOVER` на порт 45555, терминал отвечает кодом
- Пульт шлёт `YMNI_PAY;сумма;код`, терминал открывает экран оплаты
- После оплаты терминал шлёт `YMNI_RESULT;OK|FAIL` на порт 45557 пульта

## Версии (проверенная связка)
Gradle 8.7 / AGP 8.5.2 / Kotlin 1.9.24 / JDK 17 / compileSdk 34

## Оплата улыбкой
Фотография снимается через системную камеру, после снимка через 1,5 с оплата
подтверждается и результат уходит на пульт. Это демо-поток: настоящее
распознавание улыбки требует серверной платёжной интеграции.
