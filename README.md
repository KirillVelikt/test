# Юмани терминал

Терминал оплаты (Android) + пульт (Windows).

## Как это работает

- Телефон-терминал раз в 1.5 с рассылает маячок (UDP 45555) с кодом и именем.
- Пульт на ПК ловит маячок и показывает терминал в списке.
- При подключении у пульта открывается окно ввода суммы - можно платить с ПК.
- Оплата уходит на терминал (UDP 45557), на телефоне открывается экран оплаты.
- Результат (UDP 45558) возвращается на пульт со звуком.

## Экраны телефона

1. Заставка с крутящимся кольцом "поиск терминалов".
2. Главный экран: код терминала, шестерёнка настроек.
3. Экран оплаты: улыбкой (камера), картой (QR), NFC (приложить карту).
4. Кружок "оплата пройдена" с анимацией, экран сам закрывается.

## Сборка

- APK: Actions -> Build APK -> Artifacts app-debug-apk.
- EXE и установщик: Actions -> Build EXE -> Artifacts TerminalControl-EXE / Installer.

## Загрузка

`py new.py` - спросит токен и запушит всё на GitHub.
