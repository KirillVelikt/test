# TerminalControl

Панель терминалов yumani: находит терминалы в Wi-Fi-сети, редактирует заказ,
отправляет его на телефон и показывает результат оплаты и данные карты.

## Запуск из EXE
1. Собранный TerminalControl.exe запускается двойным кликом.
2. Дождитесь строки "терминал подключён" (телефон и ПК должны быть в одной Wi-Fi-сети).
3. Отредактируйте список товаров (имя, цена, количество) и нажмите "отправить заказ и оплатить".
4. На телефоне откроется окно заказов; выберите способ оплаты (улыбка, QR, NFC-карта).
5. Результат и данные карты (например, "Visa ** 4A1B") появятся в панели.

## Порты
- 45555/udp — маячок терминала
- 45556/udp — команды ПК -> терминал
- 45557/udp — ответы терминала -> ПК
